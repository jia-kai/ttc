# Archived experiments

This directory contains one-time experiment reports and minimal supporting
artifacts. It is archival only, not maintained product code or documentation.

- Treat recorded experiments as frozen historical snapshots. Do not update,
  refactor, regenerate, or repair them as part of later product changes.
- Do not make archived scripts, results, or instructions part of the normal
  build, tests, or supported workflows.
- Add a new dated subdirectory for a new experiment rather than revising an
  existing record.
- Preserve only the report and small, credential-free evidence needed to
  interpret it. Do not add credentials, raw session databases, caches, or full
  benchmark workspaces.
